## 目标

建设基于 Pi 的跨文档合规检查平台：

```text
上游任务
  -> 规则计划与资料范围冻结
  -> 文件/页面取证与受控并发
  -> Pi 候选生成
  -> 原文、哈希、页表坐标绑定验证
  -> 确定性事实抽取、跨文件关联、规则判定
  -> 任务结果与 callback outbox
```

首个检查项是 `stop_work_unload`。结果只允许 `pass`、`no_pass`、`pending`、`unverifiable`、`failed`。模型不能生成业务结论，Pi session 不能成为业务账本。

# 架构约束与实施调整

2026-10-28 工作台调整：用户要求去掉访问令牌。公开的任务、规则、运行、证据与原件 API 不再校验 `X-Inspection-Token`，浏览器直接同源请求。`/internal/*` 和 Pi worker 仍以内部令牌保护候选提交及取证工具；矿井白名单、冻结范围和原件哈希校验仍生效。公开 API 的访问边界由部署网络或网关承担：能访问服务地址的人可读取和操作已配置矿井的任务。

2026-10-28。以下决定为独立工程第一阶段的边界，避免把旧服务中的慢路径复制到新项目。

| 决定 | 原因与实现边界 |
| --- | --- |
| Python 是唯一业务账本，Pi 是取证运行时 | task/run/lease/fence、快照、结果定版与 callback outbox 必须在同一事务语义下管理；Pi session 不决定业务完成 |
| 并发同时由 Pi 和宿主控制 | Pi 一轮多工具并行不保证模型永远发出多调用；批量工具分割独立页面，宿主硬限制在途请求、超时、取消和公平性 |
| source-bound 不等于事实为真 | 原文 quote/hash/locator 只能证明来源；具体字段还要验证锚定、来源角色、事件与有效期；模型不能提交 pass/no_pass 或 verified=true |
| 覆盖为开放世界，默认 fail closed | 目录返回成功不证明观察范围完整；未检索、不可读、provider 失败、版本冲突分别记录；source_complete=false 不能 pass |
| 规则包暂为开发底稿 | 原规则表及确定性代码不替代业务审定；未实现的必要条件必须列入 coverage，不可因工具返回 JSON 正常就放行 |
| 迁移语义和纯函数，不依赖旧项目目录 | 新项目可独立安装；迁移代码和规则源记录原始 SHA256；旧服务继续做差分输入参考 |
| 模型/OCR 为外部服务 | 本项目只交付应用镜像、工具和调用配置；无权重、GPU、CUDA 或模型服务镜像 |
| 离线运行不等于断开内网 | 镜像不需要 npm/pi.dev/公网；必须连接授权的模型/OCR、OceanBase、上游和回调目标 |
| 首先按一个检查项验收 | stop_work_unload 完成真实文件、证据导航、恢复、上下游回写后再扩展；合成与本机 HTTP 测试不等于真实生产验收 |

第一阶段不承诺全月完整性、专家准确率、正式 OceanBase 与回调可达性或 30 分钟吞吐。这些均有明确目标和检验入口，待真实输入与环境证明。

## 平台核心补建决策

2026-10-28：先完成可复用底座，检查项资料取舍与判定细则暂停。检查项由可信代码注册资产、事实契约、独立事实验证器与确定性算子；任务报文不能指定Python模块。规则/算子/验证器指纹随planRevision冻结，变更要新executionId。

文件先由Python冻结并记录库存，Pi可按计划按需调用parse_file、inspect_documents及页面识别。Python工作单元持久化fence、attempt与结果，恢复复用已成功单元。模型与OCR的来源锚定仅是candidate；扫描页只能经独立签名复核回执，在新执行冻结后成为来源证据，浏览器的复核意见不改历史定版。

范围完整与执行覆盖独立：服务器只接收可信来源签名的范围证明，必须绑定矿井、周期、清单和文件字节哈希；取证覆盖还必须对必要文件/页及检索水位闭合。缺任一门不能pass。签名的声明依赖来源方认可的完整性政策，签名本身不证明源端从未漏报。

并发限额由数据库共享permit和控制worker按矿井轮转约束；Pi SDK仍使用并行工具。基准脚本记录冷/热及重复运行，缺失遥测为null，不能用单次速度证明约100文件质量或生产时延。正式模型/OCR、OceanBase、PostgreSQL和Linux容器需各自真实验收，不能从本机合成链推断。
